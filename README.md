dell'Università Ca' Foscari Venezia, A.A. 2026/2027: le note di ogni
insegnamento in formato Obsidian, le dispense PDF composte da quelle note e gli
esami di Econometria svolti passo per passo, con tutte le figure, le
esercitazioni di preparazione (esercizi e soluzioni), le tracce per l'orale di
Legislazione Bancaria e la banca di domande del test di ingresso.

> Appunti personali, non ufficiali e non rivisti dai docenti. Possono contenere
> errori: verificare sempre sul materiale del corso.

## Appunti delle lezioni

Le lezioni registrate in aula, in tre versioni della stessa lezione:

- **Accademica**: la lezione riscritta in prosa accademica.
- **Fedele**: la trascrizione ripulita, con le parole del docente, le parti sottolineate evidenziate e le figure delle slide.
- **Sintetica**: una sintesi a punti della versione fedele, con gli stessi titoli.

Ogni versione sintetica conserva i titoli di quella fedele, così si passa dal punto al testo
completo cercando il titolo. Le note sono Markdown (si leggono in Obsidian); i PDF raccolgono

## Test di ingresso — prova di verifica EMR20

647 domande a risposta multipla sul programma della prova di verifica della
personale preparazione (matematica finanziaria, finanza aziendale e analisi di

## Leggere le note in Obsidian

Aprire la cartella `obsidian/` come vault (*Open folder as vault*). Ogni
insegnamento ha una nota indice con l'ordine delle lezioni. Le note si leggono
anche direttamente su GitHub.

## Ricompilare

| Strumento | Versione usata |
|---|---|
| pandoc | 3.8 |
| TeX Live (XeLaTeX + latexmk) | 2025, con Latin Modern |
| Python | 3.12 con numpy, scipy, matplotlib, pandas, statsmodels |

```bash
cd latex
make everything        # tutte le dispense e tutto il materiale d'esame
make combined          # solo le dispense (+ volume unico)
make esami             # solo il materiale d'esame, tutti i corsi
make esercitazioni     # le esercitazioni di Econometria (24 PDF)
make figure            # rigenera le figure delle dispense
```
